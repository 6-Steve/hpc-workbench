# 界面美化（2026-11-17 已实施，待验收）

> 这里的"美化"不是换配色、加动效，而是**让同一屏里的信息更快被读对**。
> 四条原则：不加图标包、不加动画、不加字号档位、不推翻现有主题。

## 0. 先说核查结论（要修正 `docs/07` 里的两处判断）

写方案前把现状数了一遍，有两项和清单里写的不一样：

| 清单原话 | 核查结果 |
|---|---|
| "状态点大小三处不一致（1.5px/2px）" | **尺寸其实已经统一**：6 处都是 `h-1.5 w-1.5`。真正的问题是**两套视觉语言**——作业行用"胶囊标签"（border+bg+文字），其它地方用"圆点"。 |
| "数字左对齐混着" | **点数页已经是标杆**：表格 `<td>` 用了 `text-right font-mono tabular-nums`。作业页是卡片式，靠固定宽度（`w-16`/`w-28`）对齐。缺的只是资源页/隧道/传输这几处**行内指标**。 |

所以这四项的真实收益排序是 **空状态 > 数字 > 状态点 > 间距**，不是原清单的顺序。

## A. 空状态：抽一个 `EmptyState`

### 现状

| 位置 | 现在 | 评价 |
|---|---|---|
| 文件页空目录 | `<p class="px-3 py-6 text-center text-body text-ink-500">这个目录是空的</p>` | 太弱，没有"下一步" |
| 通知中心空 | `还没有通知` | 同上，且没说"什么会出现这里" |
| 隧道页空 | 已有一句解释 | 内容好，但观感与别处不一致 |
| 点数页空 | 已有一句解释 | 同上 |
| 作业页空队列 | `<Card title="队列是空的">` + 解释 | **已经是最好的一版**，作为文案范本 |

结论：**不缺文案，缺统一**。作业页那句把规则写对了——标题说"为什么空"，正文说"下一步做什么"。

### 做什么

`src/renderer/src/components/ui.tsx` 加一个组件：

```tsx
export function EmptyState({
  title,
  hint,
  action
}: {
  /** 一句话说明"为什么这里是空的" */
  title: string
  /** 下一步该做什么（可带 <Hint>/<code>） */
  hint?: ReactNode
  /** 可选的操作按钮 */
  action?: ReactNode
}): JSX.Element
```

样式（固定，不允许各页自调）：

- 外层 `flex flex-col items-center justify-center px-4 py-8 text-center`
- 标题 `text-emph font-medium text-ink-700`
- 说明 `mt-1 max-w-[46ch] text-body leading-relaxed text-ink-500`
- 按钮 `mt-3`

### 文案规则（写进注释，避免以后又回到"暂无数据"）

| 场景 | 标题 | 说明 |
|---|---|---|
| 空目录 | 这个目录是空的 | 可以从本机拖文件进来，或者点右键「新建文件夹」。 |
| 无通知 | 还没有通知 | 作业开始、结束、失败时会出现在这里。 |
| 无隧道 | 还没有隧道 | 开一条之后，关掉应用或点「关闭」都会释放端口。 |
| 无历史作业 | 最近 7 天没有作业记录 | 跑过作业之后，这里会留下记录。 |
| 无点数记录 | 还没有任何作业记录 | 跑过作业之后这里就会有数。 |

### 使用点（5 处）

`FilePane`（空目录）、`NotificationCenter`、`TunnelsView`、`PointsView`、`JobsView`（把 Card 版本换成组件，保留文案）。

> 作业页那两处是"整页空"，用 `Card` 包一层 `EmptyState` 即可，不改结构。

### 不做

- **不加插图/大图标**：这一版没有图形资源，加 emoji 会破坏现有克制的观感
- 不改 `VirtualList` 的行高常量（空态是独立分支，和虚拟滚动无关）

## B. 数字：定一条规则，补齐三处

### 规则

| 场景 | 类名 | 例 |
|---|---|---|
| 表格单元格 | `text-right font-mono tabular-nums` | 点数页（已是如此，作为标杆） |
| 行内指标（flex 卡片行） | `font-mono tabular-nums` + 固定 `w-*` | 作业页 `w-16` / `w-28`（已是如此） |
| 大数字（余额、电量） | `font-mono tabular-nums` | 标题栏电量 |

**`tabular-nums` 是 Tailwind 内置工具类**（产物里是 `.tabular-nums{font-variant-numeric:...}`），
不是项目 token，所以不需要在 `tailwind.config.js` 注册，也不受 `design-tokens` 守卫影响。
它解决的是"1 和 8 宽度不同导致数字跳"的问题。

### 要补的三处

| 位置 | 现在 | 改成 |
|---|---|---|
| `TunnelsView` 统计行（`连接 111 · 下行 4.4 MB · 上行 137 MB`） | 纯文字 | 数字段套 `font-mono tabular-nums` |
| `TransferBar` 进度（`12.3 MB / 45.6 MB`） | 纯文字 | 同上 |
| `ResourcesView` 节点行（`卡5 核48/64 62G`） | `font-mono` 但无等宽数字 | 加 `tabular-nums` |

> 只做这三处。**不重排布局**——作业页的卡片式 + 固定宽度是对的选择，不要为了"对齐"改成表格。

## C. 状态点：抽 `StatusDot`，把"两套语言"写成规则

### 现状

- 6 处圆点，尺寸已统一 `h-1.5 w-1.5`
- 作业行/历史行用**胶囊**（`border-* bg-*/[0.06] text-*`）
- 两套并存，但不同屏，暂未造成误读

### 规则（这条比组件更重要）

> **单点用圆点，带文字用胶囊。同一行内不许混用。**

理由：圆点表达"这一行有个状态"，胶囊表达"这个状态叫什么"。混在一行会让眼睛反复切换语义。

### 组件

```tsx
export function StatusDot({
  tone,
  size = 'sm',
  title
}: {
  tone: 'ok' | 'wait' | 'bad' | 'info' | 'idle'
  size?: 'sm' | 'md'
  title?: string
}): JSX.Element
```

映射与尺寸（只用已注册 token）：

| tone | 颜色 | 语义 |
|---|---|---|
| `ok` | `bg-state-ok` | 运行中 / 已连接 |
| `wait` | `bg-state-wait` | 排队 / 警告 |
| `bad` | `bg-state-bad` | 失败 / 断开 |
| `info` | `bg-state-info` | 进行中 / 提示 |
| `idle` | `bg-ink-200` | 未激活 |

`sm = h-1.5 w-1.5`（6px，列表行用）、`md = h-2 w-2`（8px，标题栏用）。

### 替换点（5 处）

`ProfileSwitcher`、`TitleBar`、`NotificationCenter`、`TerminalView`、`FilePane`（加载中那个 `animate-pulse`）。

> `FilePane` 和 `JobLogDialog` 的"活动"点保留动画（`animate-pulse` / `animate-ping`），
> 只是换成组件 + 固定尺寸——**动画是"还在转"的语义，不能顺手删掉**。

## D. 间距：三档，一次性归位

### 现状

`space-y-4` 4 处、`space-y-3` 9 处、`mt-4` 5 处、`mt-3` 7 处——用法和层级没有对应关系。

### 三档

| 层级 | 值 | 用在哪 |
|---|---|---|
| 页面级 | `space-y-4` | `PageShell` 里卡片之间（16px） |
| 卡片内 | `space-y-3` | 一张卡片里的段落组（12px） |
| 元素内 | `mt-1` / `mt-1.5` | 标题与它自己的说明（4–6px） |

### 做法

- 把"页面级却用了 `space-y-3`"的地方改成 `space-y-4`（逐个看，不批量替换）
- `mt-4` 一律降为 `mt-3`（页面级之外的间距不该到 16px）

**不写守卫测试**：间距属于审美判断，写死断言只会逼着以后绕开它（`docs/04 §2.12` 的教训）。

## 不做的四件事

| 想法 | 为什么不做 |
|---|---|
| 引入图标包（lucide/heroicons） | 现在全站是手写 SVG，加依赖会带来风格不一致 + 体积 |
| 加过渡动画 | 轮询 20 秒刷新一次，动画只会制造"在动"的错觉 |
| 新增字号档位 | 五档（`page/emph/body/sub/meta`）够用，加一档要重过对比度检查 |
| 改圆角/阴影 | 属于主题层，动它要重跑三套主题的对比度测试 |

---

## 风险与守卫

| 风险 | 对策 |
|---|---|
| `design-tokens` 的 9 条 `toEqual([])` 硬断言 | 新类名必须已注册（`h-2/w-2` 是内置，`bg-ink-200` 已注册）；改完跑一次守卫 |
| 对比度 | 空态说明用 `ink-500`（达标），**不要** `ink-400` 或 `text-*/70` |
| 虚拟滚动 | 空态不改行高常量；`FilePane` 的 `rowHeight` 一个字节都不动 |
| 守卫把注释当代码 | 注释里别写类名样式的字符串（上次 `bg-slot` 就被抓过） |
| 改一处破坏另一处 | 每步后跑 `design-tokens` + 全量测试，别攒到最后 |
